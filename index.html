Hog Bank v2.0 Enterprise Core

A full-stack, ACID-compliant banking prototype engineered with C#, ASP.NET Minimal APIs, and SQL Server. Designed to move beyond UI and implement true institutional-grade database security, algorithmic underwriting, and macroeconomic stress testing.

1. The Relational Ledger & ACID Compliance

SQL ServerDouble-Entry AccountingNormalization

At the core of Hog Bank is a strictly normalized SQL Server database. The C# backend acts purely as a stateless routing layer, deferring to secure SQL stored procedures for transaction execution.

By enforcing strict Foreign Key constraints across the Customer, Account, and Transaction tables, the system guarantees absolute data integrity. Every cent is permanently traced to a specific teller ID, terminal, and geospatial branch coordinate.

  • Check 21 Act Implementation: We built backend logic to segregate "Ledger Balance" from "Available Balance" to simulate federal check-clearing holds.

2. Proactive API & Spatial Security

C# MiddlewareSQL GeometryRedis Pattern

Legacy systems detect fraud after settlement. Hog Bank intercepts it during the request lifecycle.

Idempotency Gateways: We engineered a thread-safe cache system. Cryptographic tokens are attached to every network request; if a user double-clicks "Transfer" or the network lags, the backend instantly drops duplicate payloads, neutralizing double-spend risks.

Geospatial Intercepts: Using native SQL POINT geometry calculations, the database checks POS swipe locations. If a card is swiped in Fayetteville and Tokyo within a 5-minute window, the velocity threshold triggers an automatic system lock.

The four pillars of our database-level security arsenal.

3. B2B Payroll & High-Speed Ingestion

SQL OPENJSONBulk OperationsO(1) Efficiency

To prove the scalability of the architecture, we built a B2B clearinghouse feature designed to handle massive corporate payroll files.

Instead of using slow C# foreach loops to process thousands of transactions one by one, the application passes raw JSON payloads directly into the database. By utilizing SQL Server's native OPENJSON functionality, the backend parses, validates, and distributes funds across thousands of accounts in a single, highly optimized batch transaction.

4. Temporal Audits & Dynamic CRM

System-Versioned TablesCompliancePlaid Integration

Financial institutions operate under strict regulatory compliance (e.g., KYC rules). To meet these standards, our CRM utilizes SQL System-Versioned Temporal Tables.

When a teller updates a customer's profile (like changing an email or physical address), the old data is never overwritten. The database automatically versions the row with exact ValidFrom and ValidTo timestamps, creating an immutable "Time Machine" audit trail of every change ever made to an account.

5. Algorithmic Underwriting & DFAST

NPV ModelingMacro Stress TestingBasel III

Hog Bank does not rely on static FICO scores. We built the "HogScore" engine to dynamically assign interest rates based on 30-day trailing cash flow liquidity.

To stress-test the ledger, we implemented a live DFAST (Dodd-Frank Act Stress Test) simulator. By originating millions in toxic subprime debt, we can simulate Federal Reserve recession shock multipliers against our Net Present Value (NPV). This maps the bank's liquidity collapse, requiring the manager to execute Wall Street Asset-Backed Securitization (ABS) block trades to save the portfolio.

Simulating a Severe Adverse capital shortfall.

6. Graph Theory & AML Compliance

DFS AlgorithmsFinCEN ReportingBenford's Law

To monitor millions of synthetic transactions, we built executive-level forensic tools.

We implemented Benford's Law distribution charts to catch manipulated or fabricated ledgers. More importantly, we engineered a Depth-First Search (DFS) algorithm to map network topologies, successfully identifying and visually flagging circular Anti-Money Laundering (AML) syndicates.

Once detected, the system automatically generates federal Suspicious Activity Reports (SAR), formulating regulatory narrative text for Bank Secrecy Act violations.
